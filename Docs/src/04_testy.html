7. Testowanie

Testy przeprowadzono na trzech poziomach:

  1. Testy jednostkowe EditMode (NUnit, Unity Test Framework) – logika niezależna od sceny: zapis, ranking, sklep, misje, osiągnięcia, punktacja, plan fal, model trudności, sesja gry.
  2. Testy integracyjne PlayMode – ładowanie prawdziwych scen w edytorze i sprawdzanie przepływu gry: Boot → menu, start poziomu, spawn wrogów, pauza, śmierć gracza → Game Over, ukończenie poziomu → odblokowanie kolejnego, utrzymanie wrogów w arenie, ciągłość fal.
  3. Testy manualne na emulatorze Android – AVD Android 14 (API 34, x86_64, 1080×2400, 420 dpi), sterowanie gestami wstrzykiwanymi przez ADB (input tap, input motionevent, keyevent BACK), zrzuty ekranu przez adb exec-out screencap.

Wszystkie testy automatyczne można uruchomić skryptem Tools/verify.ps1, który generuje zawartość, uruchamia testy EditMode i PlayMode oraz buduje APK.
